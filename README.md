# NovelHub TTS assets

A download mirror for the on-device text-to-speech voices of the **NovelHub** app.

The app downloads voice packs from its main server. When that server is down, it downloads the same
files from this repository's releases, or from the twin repository on Hugging Face. Every file is
checked against the SHA-256 listed in the manifest before the app uses it.

Nothing here was created by NovelHub. The models and data come from the original projects listed
below, and they stay under the terms of those projects.

## What is here

The release [`tts-files`](../../releases/tag/tts-files) holds each file of every voice pack, named by
its SHA-256 (release assets cannot hold folders). It also holds `manifest.json` and
`manifest-staging.json`.

`manifest.json` is the index. Each pack lists its files as `path`, `size` and `sha256`, and the
release asset for a file is the one named by that `sha256`. To list a pack's files with their asset
names:

```sh
curl -sL https://github.com/vokhuyetOz/novelhub-tts-assets/releases/download/tts-files/manifest.json \
  | jq -r '.packs[] | .id as $id | .files[] | "\(.sha256)  \($id)/\(.path)"'
```

The Hugging Face mirror keeps the original folder layout:
`tts/packs/<pack id>@<version>/<path>`, voice samples under `tts/previews/`, and the manifests.

## Sources

| Pack | Language | Original model | Training data |
|---|---|---|---|
| `vi-standard-vais1000` | Vietnamese | Piper `vi_VN-vais1000-medium` — [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices/tree/main/vi/vi_VN/vais1000/medium) | [VAIS-1000](https://ieee-dataport.org/documents/vais-1000-vietnamese-speech-synthesis-corpus) |
| `en-standard-libritts` | English | Piper `en_US-libritts_r-medium` — [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_US/libritts_r/medium) | [LibriTTS-R](https://www.openslr.org/141/) |
| `hd-supertonic3` | Vietnamese + English | Supertonic 3 by Supertone — [Supertone/supertonic-3](https://huggingface.co/Supertone/supertonic-3), [supertone-inc/supertonic](https://github.com/supertone-inc/supertonic) | — |

The Piper packs also include part of the [espeak-ng](https://github.com/espeak-ng/espeak-ng) data
(Vietnamese and English only), which the voices use to turn text into phonemes.

Every model file comes from the [sherpa-onnx `tts-models` release](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models)
([k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)), which converts and repackages the
original models for ONNX Runtime. The Supertonic 3 weights there are int8-quantized versions, not the
original files. NovelHub did not retrain or fine-tune any model. It only picked the files each pack
needs and added a `pack.json`.

The MP3 samples under `tts/previews/` on the Hugging Face mirror were generated by NovelHub with
these packs. They are synthetic speech, not recordings of real people.
